# Web development

Store project requirements, design notes, source code, and QA evidence here.

For each project, create a named subdirectory with its own README covering the brief, chosen stack, prerequisites, environment variable names, setup commands, development commands, relevant checks, and deployment process. Select the stack from the project requirements.

Suggested project contents: requirements, design, application source, and QA notes. Create these as needed rather than adding empty placeholders.

Coordinate with the [UI/UX Designer](../agents/ui-ux-designer.md), [Web Developer](../agents/web-developer.md), [SEO Specialist](../agents/seo-specialist.md), and [Analytics Specialist](../agents/analytics-specialist.md). Use the [shared workflow](../docs/team-workflow.md) for handoffs.
