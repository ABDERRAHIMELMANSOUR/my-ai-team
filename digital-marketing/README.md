# Digital marketing

Store project-specific strategy, search research, content, campaign proposals, measurement plans, and performance reports here.

For each project, create a named subdirectory linked to its project brief. Add SEO, content, paid media, and analytics deliverables as needed. Include the audience, objective, owner, status, source evidence, and review criteria in each deliverable.

Reports must state dates, timezone, currency where relevant, metric definitions, data sources, and attribution settings. Campaign proposals must specify budget, targeting, creative, destination, and measurement. Label forecasts and assumptions.

Coordinate with the [SEO Specialist](../agents/seo-specialist.md), [Content Marketer](../agents/content-marketer.md), [Paid Ads Specialist](../agents/paid-ads-specialist.md), and [Analytics Specialist](../agents/analytics-specialist.md). Follow the [shared workflow](../docs/team-workflow.md). Publication and spend require authorization.
