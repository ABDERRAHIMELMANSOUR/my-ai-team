# Web Development & Digital Marketing AI Team

A shared workspace for planning, building, and growing websites with a coordinated AI team.

## Start here

1. Copy [the project brief template](docs/project-brief-template.md) into a project-specific document and fill in the goals and constraints.
2. Follow [the team workflow](docs/team-workflow.md) to assign tasks and hand off deliverables.
3. Use the role guides in [agents/](agents/) and the repository instructions in [AGENTS.md](AGENTS.md).

## Structure

| Path | Purpose |
| --- | --- |
| `agents/` | Responsibilities, inputs, outputs, and review criteria for each role |
| `docs/` | Shared workflow and project briefs |
| `web-development/` | Website requirements, designs, implementation, and QA |
| `digital-marketing/` | SEO, content, campaigns, and performance reports |

## Team

Team Lead, Web Developer, UI/UX Designer, SEO Specialist, Content Marketer, Paid Ads Specialist, and Analytics Specialist.

These files define roles and working practices. They do not provision autonomous agents, connect accounts, or run campaigns. Choose the application framework and integrations when a project brief requires them.

## Working agreements

Keep deliverables tied to a brief and measurable acceptance criteria. Record assumptions and evidence. Never commit credentials, personal customer data, or private account exports. Publishing, deployment, and advertising spend require authorization for the specific action.
