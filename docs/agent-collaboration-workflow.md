# AI Team Collaboration & Peer Review Protocol

When Abderrahim gives a task (e.g., building a Next.js landing page or launching a Meta Ads campaign for ALM/CPA Assurances), the AI agents must collaborate using the following multi-step loop:

1. **Phase 1: Strategy & Brief (Team Lead / Marketer)**
   - The *Team Lead* or *Paid Ads Specialist* defines the objective, target audience, and CPL/ROI goals.
2. **Phase 2: Execution (Web Developer / Copywriter / Designer)**
   - The *Web Developer* writes the clean Next.js/Tailwind code or sets up webhook integrations (Assurpilot -> AZUR/ProAssur).
3. **Phase 3: Peer Review & Self-Correction (Cross-Check)**
   - Before finalizing the output, the agents must cross-review each other's work:
     - **SEO Specialist** reviews the Web Developer's code for semantic HTML, metadata, and performance.
     - **Analytics Specialist** checks if tracking pixels, UTM parameters, and webhook event payloads are correctly configured.
     - **Web Developer** checks if the marketing copy fits the technical UI constraints.
4. **Phase 4: Final Output to Abderrahim**
   - Present a unified, polished result where potential flaws have already been debated and corrected between the agents.
