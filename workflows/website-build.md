# Website Build

From brief to a launched website.

| # | Step | Owner | Output |
|---|---|---|---|
| 1 | Complete the brief and brand file | Lead with human | `brief.md`, `brand.md` |
| | **Gate G1: Brief** | Human | |
| 2 | Research and positioning | strategist | `deliverables/strategy.md` |
| 3 | Keyword map and on-page direction | seo-specialist | `deliverables/seo/` |
| 4 | Sitemap, page structure, design tokens | ux-designer | `deliverables/ux.md` |
| | **Gate G2: Direction** | Human | |
| 5 | Page copy | copywriter | `deliverables/copy/` |
| 6 | Tracking plan | analytics | `deliverables/tracking-plan.md` |
| 7 | Build and deploy to preview | web-developer | Preview URL |
| 8 | Cross-review of SEO, tracking and copy fit | seo-specialist, analytics, web-developer | Fix list |
| 9 | Fix issues from step 8 | web-developer | Updated preview |
| 10 | Independent review | qa-reviewer | `deliverables/qa-report.md` |
| | **Gate G3: Launch** | Human | |
| 11 | Deploy to production, smoke test | web-developer | Live URL |
| 12 | Confirm live tracking and indexing | analytics, seo-specialist | Handoff to lead |

Steps 5 and 6 can run in parallel. A QA failure returns to the owner of the failing work, then repeats step 10.
